LAB PROCEDURE
Variac Protocol
  1. Select governor rig from the top toolbar and set physical dimensions on the left.
  2. Slowly increase spindle speed with the Variac until the sleeve lifts.
  3. Click Record Reading at each stabilized speed (always increase speed monotonically).
  4. Inspect characteristic curves, Matplotlib 3D simulation, and observation table across tabs.
